特長

「飾る」に特化した、軽くてシンプルなアプリ

🗂️

好きな画像を自由に

PNG・JPEG・GIF・TIFF・HEICに対応。好きな画像を何枚でも登録して、気分に合わせて切り替えられます。

🖼️

いつでも最前面に

透過ウィンドウで画像を常に最前面に表示。すべての仮想デスクトップに対応し、他のウィンドウに隠れません。

🖱️

直感的な操作

ドラッグで移動、スクロールでサイズ変更、画像ファイルのドロップで追加。回転や不透明度もパネルから調整。Option + H で全画像を一括表示/非表示、Option + Shift + H で現在の画面のみ切り替え。個別ウィンドウの非表示にも対応。右クリックメニューですべての操作にすぐアクセスできます。

✂️

画像の切り取り

iPhone写真アプリ風のクロップエディタ。矩形・円形・角丸矩形の形状クロップ、アスペクト比プリセット、傾き・パースペクティブ補正、Undo/Redo対応の非破壊編集。

✂️

かんたん背景除去

JPEG・HEICなどの写真から被写体を自動で切り抜き。透過PNGを準備する手間なく、お気に入りの写真をそのまま飾れます

🗂️

管理パネル

すべてのウィンドウをひとつのパネルで管理。ミニマップで配置確認、位置・サイズの数値編集、レイアウトプリセット管理、画像ライブラリ管理、各種設定が一画面に。

詳細を見る →

位置・サイズ・画像・回転・不透明度・重ね順・非表示状態は自動保存。アップデートもアプリ内から確認できます。

使い方

かんたん3ステップで、すぐに飾れます

1

インストールして起動

Homebrewでワンコマンド。起動するとメニューバーにアイコンが現れ、デスクトップに画像が表示されます。

brew install --cask shiroemons/tap/sobani

または Sobani-universal.dmg を直接ダウンロードすることもできます。

⚠️ 初回起動時に「開発元が未確認」と表示された場合は、Sobani.appを右クリック →「開く」を選択してください。

2

お気に入りの画像に差し替える

メニューバーから「デフォルト画像を変更...」を選んで、好きな画像を設定するだけ。
右クリック →「表示画像の変更」で、画像の追加登録や切り替えもできます。

💡 ヒント: スマホで撮った写真（JPEG）もそのまま使えます。特別な加工は必要ありません。

3

好きなように配置する

ドラッグで移動、スクロールでサイズ変更。
右クリックから「画像を追加表示」で画像を増やしたり、「表示の調整」で回転・不透明度・左右反転を調整したり。自由にデスクトップを飾りましょう。

💡 ヒント: Optionキーを押しながら操作すると、すべてのウィンドウをまとめて動かせます。

Sobaniは「Macのデスクトップに画像を飾る」ことに特化した、無料の画像最前面表示アプリです

Sobani 一般的な画像オーバーレイアプリ
価格 完全無料・OSS 無料〜有料（$4.99〜）
背景除去 ワンクリック（Vision AI） なし or 外部ツール必要

ゴーストモード クリック透過＋不透明度調整 一部対応
対応画像形式 JPEG/PNG/GIF/TIFF/HEIC（スマホ写真もそのまま） PNG中心
