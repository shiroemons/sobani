# Sobani ユーザーペルソナ

本ドキュメントは、Sobani（デスクトップアクスタアプリ）のユーザーペルソナを定義したものです。プロダクト設計、UXテスト、マーケティング戦略、ドキュメント改善の基盤として活用することを目的としています。各ペルソナは、実際のユーザー調査・フィードバックおよび想定ユースケースに基づいて構築されており、開発チームが「誰のために作っているのか」を常に意識できるようにしています。

---

## ペルソナ 1: 佐藤 凛（さとう りん）

| 項目 | 詳細 |
|------|------|
| **年齢** | 21歳 |
| **職業** | 大学生（文学部 日本文学科 3年） |
| **居住地** | 東京都杉並区（一人暮らし） |
| **使用端末** | MacBook Air M2（メモリ8GB） |
| **OS** | macOS Sonoma 14.x |
| **技術習熟度** | ★★★☆☆（日常的にMacを使うが、ターミナル操作は不慣れ） |
| **ユーザー分類** | コアターゲット：推し活・アニメファン |

> **「推しはいつだってそばにいてほしい。レポート書いてるときも、動画見てるときも。」**

### 背景

凛は熱心なアニメファンで、複数の作品を同時に追いかけている。毎クール5〜6本のアニメを視聴し、推しキャラクターのグッズを積極的に収集している。X（旧Twitter）では推し活アカウントを運用しており、デスクトップのスクリーンショットを「推しデスクトップ」として定期的に投稿している。透過PNG素材はPixivやBoothで入手することが多い。同人イベントにも参加しており、ファンコミュニティでの交流が日常の一部になっている。

MacBookは大学入学時に購入し、レポート作成、講義資料の閲覧、動画視聴に使用している。Homebrewの存在は知っているが、自分でインストールした経験はない。

### 目標

- お気に入りのキャラクターを作業中のデスクトップに常時表示したい
- 複数の推しキャラクターを簡単に切り替え・並べて表示したい
- 見映えの良いデスクトップレイアウトを作り、SNSでシェアしたい
- バッテリー消費を気にせず常駐させたい

### フラストレーション

- 透過PNG素材の準備方法がわからない（背景の切り抜き方など）
- 初回起動時にDockにアイコンが出ないため、アプリがどこにあるか迷う
- Homebrewのインストールがターミナル操作を伴うため心理的ハードルが高い
- バッテリーやメモリへの影響が不安（常駐アプリへの漠然とした懸念）
- キャラクター画像のサイズ調整が直感的でない場面がある

### 発見経路

Xのタイムラインで、フォロワーが投稿した「推しデスクトップ」のスクリーンショットを見て興味を持った。ツイートに添付されたSobaniへのリンクから存在を知った。

### 機能優先度

1. 画像の簡単な追加・削除
2. 複数ウィンドウの同時管理
3. サイズ変更・配置の直感的操作
4. クイック切り替え（表示/非表示）

### 利用シナリオ

1. **発見** — Xのタイムラインで、フォロワーが投稿したデスクトップスクリーンショットを見る。画面上にアニメキャラクターが透過表示されている様子に「かわいい！これ何のアプリ？」と反応する。
2. **情報収集** — ツイートのリプライ欄で「Sobani」というアプリ名を知る。GitHubのリンクを開くが、英語混じりのREADMEに少し戸惑う。「Homebrewでインストール」という手順を見て、ターミナルを開くことに不安を感じる。
3. **インストール** — 友人にLINEで相談し、`brew install --cask sobani` のコマンドをコピペしてインストールを完了する。Gatekeeperの警告が表示されるが、友人の「大丈夫だよ」という助言で続行する。
4. **初回起動の戸惑い** — アプリを起動するが、Dockにアイコンが表示されない。「あれ、起動してない？」と焦り、もう一度ダブルクリックする。しばらくしてメニューバーにアイコンが増えていることに気づく。
5. **メニューバーの発見** — メニューバーのSobaniアイコンをクリックし、メニューが表示される。日本語のメニュー項目に安心する。「画像を追加表示」をクリックし、事前にダウンロードしておいた推しキャラの透過PNGを選択する。
6. **最初のキャラクター表示** — デスクトップにキャラクターが表示され、「おおっ！」と声が漏れる。スクロールホイールでサイズを調整し、ドラッグして画面右下の定位置に移動する。
7. **2体目の追加** — 「もう一人の推しも表示したい」と思い、再度メニューから別のキャラクター画像を追加する。2体が並んでいる様子に満足する。
8. **レイアウトの調整** — 右クリックメニューから反転機能を発見し、キャラクター同士が向かい合うように配置する。「会話してるみたい！」とテンションが上がる。
9. **スクリーンショット撮影** — Command+Shift+3でデスクトップ全体のスクリーンショットを撮影する。壁紙・キャラクター配置のバランスを何度か調整してから、納得の一枚を撮る。
10. **SNSでシェア** — 「推しデスクトップ完成した！Sobaniっていうアプリ使ってるよ」とXに投稿。フォロワーから「何これ！教えて！」とリプライが来る。
11. **日常利用の定着** — 毎朝MacBookを開くと推しキャラクターが表示されている状態が日常になる。クールが変わると新しい推しの画像に入れ替える。Option+Hで授業中はサッと非表示にし、休み時間に再表示するのがルーティンになる。

## ペルソナ 2: 田中 幸子（たなか さちこ）

| 項目 | 詳細 |
|------|------|
| **年齢** | 42歳 |
| **職業** | パート主婦（週3日、事務補助） |
| **居住地** | 神奈川県横浜市（戸建て、夫・娘と3人暮らし） |
| **使用端末** | iMac 24インチ（2023年モデル） |
| **OS** | macOS Sonoma 14.x |
| **技術習熟度** | ★★☆☆☆（Webブラウジング、メール、写真管理が中心） |
| **ユーザー分類** | カジュアルユーザー：ペット・家族写真 |

> **「パソコンを開くたびにモコ（愛犬）がいてくれると、なんだかホッとするんです。」**

### 背景

幸子は家庭の経理、町内会の書類作成、ネットショッピングなどでiMacを日常的に使っている。技術的な知識は限定的で、アプリのインストールは基本的にApp Storeから行う。ターミナルの存在は知っているが、一度も開いたことがない。

愛犬のトイプードル「モコ」の写真をiPhoneで大量に撮影しており、iCloudで同期されたMacの写真ライブラリには数千枚のペット写真がある。娘（17歳・高校生）がIT関連に詳しく、Macの設定やトラブル対応は娘に頼ることが多い。

### 目標

- 愛犬や家族の写真をデスクトップに常に表示しておきたい
- 複雑な操作なしでシンプルに使いたい
- パソコンに負担をかけたくない（「重くならないか」が常に心配）
- 日常の作業を邪魔しない程度にさりげなく表示したい

### フラストレーション

- 「透過PNG」が何なのか全くわからない（通常のJPEG写真しか持っていない）
- Homebrewでのインストールは自力では不可能（ターミナルが怖い）
- メニューバーアイコンが小さく、他のアイコンに埋もれて見つけにくい
- Gatekeeperの警告メッセージが怖い（「悪意のあるソフトウェア」という表現に不安を感じる）
- 右クリックメニューの項目が多く、どれを選べばいいか迷う

### 発見経路

高校生の娘が「お母さん、モコの写真いつもデスクトップに置きたいって言ってたよね？こんなアプリあるよ」と教えてくれた。

### 機能優先度

1. シンプルで迷わない操作
2. 日本語でのわかりやすい表示
3. JPEG写真がそのまま使えること
4. サイズ・不透明度の簡単な調整

### 利用シナリオ

1. **きっかけ** — 娘が夕食後に「お母さん、こんなアプリあるよ」とSobaniを紹介する。「デスクトップにモコの写真を飾れるんだって」という説明に興味を示す。
2. **インストール（娘による）** — 娘がターミナルを開き、Homebrewのインストールから `brew install --cask sobani` まで実行する。幸子は横で見ているが、黒い画面に白い文字が流れる様子に「なんか怖い...」とつぶやく。
3. **Gatekeeper警告への対処** — 初回起動時に「開発元を確認できません」という警告が表示される。「大丈夫なの？ウイルスじゃないの？」と心配するが、娘が「GitHubっていうちゃんとしたところで公開されてるから大丈夫だよ」と説明し、システム設定から許可する。
4. **メニューバーの発見** — 娘が「ここにアイコンがあるよ」とメニューバーを指す。幸子は「こんなところに！全然気づかなかった」と驚く。メニューバーのアイコンが小さいことに少し不満を感じる。
5. **写真の追加** — 「画像を追加表示」をクリックし、写真ライブラリからモコのお気に入りJPEG写真を選択する。透過PNGではないため背景が四角く表示されるが、「モコがいる！かわいい！」とまず喜ぶ。
6. **JPEG写真でも使えることの発見** — 透過でなくても表示できることに安心する。「写真をそのまま使えるんだ。透明じゃなくてもいいのね」と理解する。フォトフレームのような使い方もアリだと感じる。
7. **サイズと位置の調整** — スクロールホイールで写真を小さくし、画面右下の隅に移動する。「ここなら邪魔にならないわね」と定位置を決める。
8. **不透明度の調整** — 娘に教えてもらい、右クリックから調整パネルを開く。不透明度スライダーを動かし、50%程度に設定する。「うっすら見えるくらいがちょうどいい」と満足する。
9. **家族に見せる** — 夫が帰宅後、「見て見て、パソコンにモコがいるの」とデスクトップを見せる。夫は「へぇ、おもしろいね」と反応する。
10. **日常への定着** — 毎朝iMacを起動すると、画面の隅にモコの写真が半透明で表示されている。パートの経理作業中もモコが見えることに小さな幸せを感じる。
11. **追加写真への欲求** — 1ヶ月後、「家族旅行の写真も追加したいな」と思い、娘に聞かなくても自分でメニューバーから2枚目の写真を追加できるようになっている。少しずつ操作に慣れてきた自分に小さな達成感を覚える。

## ペルソナ 3: 中村 拓海（なかむら たくみ）

| 項目 | 詳細 |
|------|------|
| **年齢** | 29歳 |
| **職業** | バックエンドエンジニア（Web系スタートアップ勤務） |
| **居住地** | 大阪府大阪市（マンション、一人暮らし） |
| **使用端末** | MacBook Pro 14インチ M3 Pro（メモリ36GB） |
| **OS** | macOS Sequoia 15.x |
| **技術習熟度** | ★★★★★（Swift経験あり、OSSコントリビューション経験多数） |
| **ユーザー分類** | パワーユーザー & OSSコントリビューター |

> **「外部依存ゼロのネイティブSwiftアプリ、しかもちゃんと動く。こういうのが好きなんだよ。」**

### 背景

拓海はGo/Rustをメインに使うバックエンドエンジニアだが、Swiftにも親しみがあり、個人でiOSアプリを開発した経験がある。GitHub上でOSSプロジェクトを定期的にチェックしており、クリーンなアーキテクチャを持つプロジェクトに貢献するのが趣味の一つ。

仕事では複数の仮想デスクトップ（Spaces）を使い分けており、デスクトップ環境の効率化に強いこだわりを持つ。Homebrewは日常的に使用し、ターミナルでの作業が主体。ウィンドウマネージャー（yabai/Amethyst等）も使っている。

### 目標

- デスクトップのワークフローをカスタマイズして効率化したい
- クリーンなコードベースのOSSプロジェクトに貢献したい
- ネイティブアプリのパフォーマンス特性を理解・評価したい
- 将来的にはスクリプトやCLIから操作を自動化したい

### フラストレーション

- CLIインターフェースがないため、自動化やスクリプティングができない
- AppleScriptやShortcutsとの連携がサポートされていない
- 設定がGUIのみで、設定ファイル（dotfileなど）による管理ができない
- ウィンドウの位置指定がピクセル単位では正確でない場面がある
- `window_states.json` のスキーマが非公開で、直接編集するのが不安

### 発見経路

GitHubの「Swift」トピックを巡回中に発見。「minimal dependencies」というREADMEの記載に目が止まり、ソースコードを読み始めた。

### 機能優先度

1. クリーンで読みやすいコードベース
2. 拡張性・カスタマイズ性
3. 低リソース消費・高パフォーマンス
4. CLI/スクリプティングオプション

### 利用シナリオ

1. **発見** — GitHubの「Explore」ページでSwiftプロジェクトを巡回中、Sobaniのリポジトリを発見する。「Desktop mascot for macOS — minimal external dependencies」という説明文に興味を引かれる。
2. **ソースコード調査** — まずREADMEを読み、次に `main.swift`、`AppDelegate.swift`、`Constants.swift` とソースコードを順に読み進める。NSWindowのフラグ設定やZ-order管理のアプローチに感心する。「`collectionBehavior = [.canJoinAllSpaces, .fullScreenAuxiliary]` か、なるほど」とつぶやく。
3. **インストール** — `brew install --cask sobani` で即座にインストール。ターミナルから `open -a Sobani` で起動する。
4. **リソース使用量の確認** — 起動直後にActivity Monitorを開き、CPU使用率とメモリ消費を確認する。アイドル時のCPU使用率がほぼ0%であることに満足する。「ネイティブアプリはこうでなくちゃ」と納得する。
5. **複数Spacesでのテスト** — Mission Controlで4つのSpacesを切り替え、すべてのデスクトップにキャラクターが表示されていることを確認する。`canJoinAllSpaces` が正しく機能していることに頷く。
6. **設定ファイルの調査** — `~/Library/Application Support/Sobani/` ディレクトリを確認し、`window_states.json` の内容を `cat` で表示する。JSONスキーマを読み解き、各フィールドの役割を推測する。
7. **制限値の確認** — `Constants.swift` を開き、ウィンドウサイズの最小値（100px）・最大値（6000px）、スクロール速度の倍率などの定数を確認する。「ここを変えればカスタマイズできるな」と考える。
8. **Issueの起票** — 「CLIインターフェースの追加」というFeature Requestをissueとして起票する。ユースケースとして「`sobani add --image ~/path/to/image.png --position 100,200 --size 300` のようなCLI操作を想定」と具体的に記載する。
9. **フォークと実装** — リポジトリをフォークし、小さな改善（ログ出力の追加やコードコメントの修正など）を実装する。コーディング規約やSwiftLintの設定を確認してからコードを書く。
10. **PRの提出** — Conventional Commitsの形式でコミットし、PRを提出する。CIが通ることを確認し、変更内容の説明と動作確認手順を丁寧に記載する。
11. **継続的な利用と監視** — PRがマージされた後も、リリースノートを定期的にチェックする通常のユーザーとして定着する。新バージョンが出るたびにChangelogを読み、アーキテクチャの変化を追い続ける。

## ペルソナ 4: 水瀬 あおい（みなせ あおい）

| 項目 | 詳細 |
|------|------|
| **年齢** | 25歳 |
| **職業** | グラフィックデザイナー（フリーランス） |
| **居住地** | 福岡県福岡市（マンション、一人暮らし） |
| **使用端末** | MacBook Pro 16インチ M2 Max（メモリ64GB） + 外部モニター27インチ |
| **OS** | macOS Sonoma 14.x |
| **技術習熟度** | ★★★★☆（デザインツールに精通、ターミナルもある程度使える） |
| **ユーザー分類** | VTuberコミュニティ & コンテンツクリエイター |

> **「デスクトップそのものをキャンバスにする。推しの配置も、角度も、不透明度も、全部こだわりたい。」**

### 背景

あおいはフリーランスのグラフィックデザイナーで、主にVTuber関連のファンアート制作、配信用素材のデザイン、サムネイル作成を手がけている。Photoshop・Illustrator・Figmaを日常的に使用しており、透過PNG素材の作成はお手のもの。

VTuberコミュニティに深く関わっており、Discordの複数サーバーに参加している。自身の配信活動（ファンアート制作の配信）も行っており、OBSでのデスクトップキャプチャ時にSobaniで表示したキャラクターを映り込ませる演出も行う。Xでは「推しデスクトップレイアウト」のスクリーンショットを定期的に投稿し、レイアウトのコツを共有するスレッドも作成している。

### 目標

- 視覚的に美しいデスクトップコンポジションを作り上げたい
- 回転・不透明度・反転を活用したアーティスティックな配置を実現したい
- 配信やスクリーンショットで映えるレイアウトを素早く構築したい
- デュアルモニター環境で統一感のある配置を行いたい

### フラストレーション

- ウィンドウのピクセル単位での精密な位置指定ができない（数値入力が欲しい）
- レイアウトプリセットの保存・切り替え機能がない
- APNG（アニメーションPNG）のアニメーション再生が理想通りではない
- 高解像度画像（4K以上）の表示品質をさらに向上させたい
- 複数ウィンドウの一括操作（全体の回転角度を揃えるなど）がもっと柔軟だと嬉しい

### 発見経路

VTuberファンのDiscordサーバーで、他のメンバーが「デスクトップにキャラを飾れるアプリ」としてSobaniを紹介しているのを見た。

### 機能優先度

1. 回転・不透明度の細かな制御
2. 精密な位置指定
3. 高画質表示（Retina対応）
4. 複数ウィンドウの効率的な管理

### 利用シナリオ

1. **発見** — VTuberファンのDiscordサーバーの「#便利ツール」チャンネルで、あるメンバーが「macOSでデスクトップに推しを飾れるアプリ見つけた！」とSobaniのリンクを共有しているのを見る。添付されたスクリーンショットのレイアウトに目を引かれる。
2. **インストール** — Homebrewは仕事で使っているためすぐにインストール完了。起動後、メニューバーアイコンもすぐに見つける。「メニューバーアプリなのね、Dockが散らからなくていい」と好印象。
3. **素材の準備** — Photoshopで推しVTuberのファンアートから透過PNGを複数書き出す。キャラクター単体の立ち絵、表情差分、小道具の素材など、サイズとバリエーションにこだわって準備する。
4. **最初の配置** — メインキャラクターの立ち絵を追加し、画面の中央下部に大きめに配置する。「やっぱり透過PNGだときれいに馴染むな」と満足する。
5. **回転の活用** — 右クリックから調整パネルを開き、回転ダイアルを操作する。キャラクターを15°傾けて動きのあるポーズに見せる。5°刻みのスナップ機能に「ちょうどいい粒度」と感じる。
6. **不透明度によるレイヤー効果** — 2体目のキャラクターを追加し、不透明度を40%に設定。メインキャラクターの背後に配置して奥行き感を演出する。「まるでレイヤー合成みたい」とデザイナーらしい使い方を見出す。

颯太は「撮り鉄」を中心とした鉄道ファンで、週末になると静岡・長野・山梨エリアを中心に一眼レフカメラを抱えて撮影に出かける。α7 IVで撮影した車両写真はRAW現像後にJPEGで書き出しており、特急・通勤・貨物を問わず撮影枚数は年間1万枚を超える。Lightroom Classicで現像した鉄道写真はフォルダ管理が徹底されており、「車両形式×撮影地×年月」のフォルダ構造で整理されている。

趣味として鉄道模型（Nゲージ）も楽しんでおり、模型車両のカタログや有志が作成したイラスト素材もコレクションしている。自宅の外部モニターには常に複数のウィンドウを広げており、鉄道写真の現像作業とプライベートの調べ物を並行して行う。Pythonで撮影記録をCSV管理するスクリプトを自作するほどの技術志向で、Homebrewは日常的に活用している。

### 目標

- 自分で撮影・現像した鉄道写真をデスクトップに飾り、作業中の気持ちを高めたい
- 横長構図の鉄道写真を画面の端に無理なく配置したい
- 模型車両の公式イラストや有志作成の透過素材も組み合わせて表示したい
- 月ごとにお気に入りの1枚に入れ替えるカレンダー的な楽しみを作りたい

### フラストレーション

- 一眼で撮った写真は横長（16:9や3:2）が多く、縦画面の端に配置するには構図が崩れやすい
- 高画質JPEG（25MB以上）を表示したときの読み込み感（ラグ）が気になる場面がある
- 外部モニターとMacBook本体の画面で同じ鉄道写真を並べたいが、解像度差による見栄えの違いが生じる
- 月替わりで画像を入れ替えるとき、前の月の配置設定（サイズ・位置）をそのまま引き継ぎたいが手動で調整し直しになる
- 有志が公開するイラスト素材の利用規約によっては個人用途のみで使えるため、SNS投稿に使えるかどうか判断が毎回必要

### 発見経路

鉄道写真愛好家が集まるXのコミュニティで、同じ撮り鉄仲間が「デスクトップに撮った車両写真を飾るのにSobani使ってる」と投稿しているのを見た。外部モニター環境でも使えると聞き、さっそく試した。

### 機能優先度

1. JPEG・PNG問わず高画質表示
2. 横長素材を画面端に無理なく配置できる自由な位置・サイズ調整
3. 外部モニターへの対応（全仮想デスクトップ表示）
4. 複数ウィンドウで車両写真と模型イラストを同時表示

### 利用シナリオ

1. **発見** — Xの撮り鉄コミュニティで、交流のある仲間が「デスクトップにSobaniで撮った車両写真を飾ってる」と投稿する。外部モニターにも対応していると書かれており、自分の環境でも使えると確信する。
2. **インストール** — GitHubのページを確認し、`brew install --cask sobani` でインストールする。Homebrewを日常的に使っているため数秒で完了する。「ゼロ依存のネイティブSwiftアプリか、軽そうでいい」とREADMEを読んで好印象を持つ。
3. **素材の選定** — Lightroomのライブラリを開き、先月の「静岡・由比ガ浜での373系撮影」の中からベストカットを1枚選ぶ。普段通りLightroomでJPEGに書き出し、Sobani用フォルダに保存する。
4. **最初の表示** — 「画像を追加表示」から書き出した写真を選択する。横長の車両写真がデスクトップに表示される。「おお、ちゃんと出た」と確認し、スクロールホイールでサイズを調整する。
5. **横長素材の配置調整** — 画面下部の帯状のエリアに鉄道写真を横長のまま配置しようとする。何度かサイズと位置を試行錯誤し、「画面下端に走行シーンを配置して俯瞰するような構図」という配置に落ち着く。
6. **模型イラスト素材の追加** — 鉄道模型メーカーの公式サイトで公開されているNゲージ車両の透過PNGイラストを追加する。実写の写真と並べて配置し「実物と模型が並んでるの、なんかいい」と楽しむ。
7. **外部モニターへの展開** — 外部モニター側にも別の車両写真を追加する。メインモニターに特急、外部モニターに通勤電車というテーマ分けで配置し、両画面で統一感のある鉄道デスクトップが完成する。
8. **不透明度の調整で現像作業への配慮** — Lightroom作業中は写真の色評価に影響しないよう、表示中の鉄道写真を不透明度30%に下げる。「現像の邪魔にならない存在感にする」という使い方を見つける。
9. **撮り鉄仲間への紹介** — Xのコミュニティで「外部モニターにも展開できて横長写真も問題なく配置できた」と報告する。自分のデスクトップ構成のスクリーンショットを添付し、「これで作業しながら撮影した路線を思い出せる」とコメントする。
10. **月替わりの更新ルーティン** — 月初になると先月撮影した中からベスト1枚を選んで入れ替えるルーティンが生まれる。「Sobani用のベストショット選び」が月初の楽しみになり、写真選別のモチベーションにもなる。
11. **季節ごとのコンセプト** — 春は桜バック、夏は海沿い、秋は紅葉、冬は雪景色という具合に季節感のある1枚を選ぶようになる。デスクトップが季節の記録にもなり、Sobaniが鉄道写真ライフの「飾り棚」として欠かせない存在になる。

## ペルソナ 12: 伊藤 ひかる（いとう ひかる）

| 項目 | 詳細 |
|------|------|
| **年齢** | 22歳 |
| **職業** | 専門学校生（情報システム科 2年） |
| **居住地** | 神奈川県川崎市（アパート、一人暮らし） |
| **使用端末** | MacBook Air 15インチ M2（メモリ8GB） |
| **OS** | macOS Sequoia 15.x |
| **技術習熟度** | ★★★☆☆（学校でプログラミングを学んでおり、ターミナルは授業で使うが深くは触らない） |
| **ユーザー分類** | VTuberファン（視聴者） |

> **「推しが配信してる時間、デスクトップに立ち絵を飾っておくと一緒にいる気分になれる。」**

### 背景

ひかるは複数のVTuberを推しており、放課後から夜にかけてYouTubeやTwitchの配信を視聴しながら課題や自主学習を進めることが多い。特定のVTuberの切り抜き動画を日常的に見ており、そこから立ち絵や公式グッズのビジュアルを入手することが多い。VTuber事務所の公式サイト・グッズ販売ページ・ファンアート公開プラットフォーム（Booth等）から素材を集めており、自分でイラストを描いたり素材を加工したりはしないが、インターネットからの素材収集は得意だ。

推しVTuberの配信中、「一緒にいる感覚」を大切にしており、デスクトップに推しの立ち絵を常時表示することで「推しに見守られながら勉強している」雰囲気を演出したいと思っていた。XやDiscordの推しVTuberのファンコミュニティに参加しており、同じファン同士での情報共有・グッズ交換なども楽しんでいる。

### 目標

- 推しVTuberの公式立ち絵や切り抜き素材をデスクトップに常時表示したい
- 配信視聴中と勉強中、どちらの場面でも「推しと一緒にいる」雰囲気を作りたい
- 配信のスケジュールや推しのイベントに合わせて表示する立ち絵を簡単に切り替えたい
- MacBook本体のパフォーマンスに影響なく軽量に常駐させたい

### フラストレーション

- 公式配布素材や購入したグッズのビジュアルが透過PNGでない場合があり、背景が残ったまま表示されてしまう
- Homebrewの導入は授業で少し触れた程度で、コマンド操作に自信がなく手順を慎重に確認しないと不安
- Gatekeeperの「開発元を確認できません」という警告メッセージが毎回緊張する
- 画面上で立ち絵とブラウザ・Notion等のウィンドウが重なり、推しが隠れてしまう
- 推しVTuberが事務所を移籍・卒業した際に、古い立ち絵素材を使い続けていいのか利用規約が気になる

### 発見経路

推しVTuberのファンが集まるDiscordサーバーの「#便利ツール」チャンネルで、他のファンが「Macで推しの立ち絵をデスクトップに飾れるアプリ」としてSobaniを紹介しているのを見た。投稿に添付されていた「推しと一緒に勉強した」というスクリーンショットを見て「自分もやりたい」と思った。

### 機能優先度

1. 透過PNG素材のきれいな表示
2. アプリの軽さ（MacBook Airへの負荷が少ないこと）
3. Option+Hによる一括非表示（授業や作業の集中タイム）
4. 複数の推し立ち絵を並べて同時表示

### 利用シナリオ

1. **発見** — 推しVTuberのファンDiscordサーバーで「Macで推しをデスクトップに飾れるアプリあるよ」という投稿を見かける。添付されたスクリーンショットに推しの立ち絵が透過表示されており、「これ絶対やりたい」と思う。
2. **情報収集** — GitHubのページを開き、スクリーンショットとREADMEを読む。「Homebrew使ってインストール」という手順に少し不安を感じるが、Discordで「簡単だよ、コピペするだけ」と教えてもらって挑戦することにする。
3. **インストール** — Homebrewをまだ入れていなかったため、公式サイトのインストールコマンドを慎重にコピペして実行する。次に `brew install --cask sobani` を実行し、無事に完了する。「黒い画面怖いけどできた！」と安堵する。
4. **Gatekeeper対応** — 初回起動で警告が出る。Discordでファン仲間に「これ大丈夫？」と確認すると「GitHubでオープンソースで公開されてるから安全だよ」と教えてもらい、システム設定から許可して起動する。
5. **素材の準備** — 推しVTuberの事務所公式サイトに「ファンによる個人利用」を許可する素材配布ページがあったことを思い出し、そこから透過PNG版の立ち絵をダウンロードする。「ちゃんと利用規約確認した」と自分に言い聞かせて安心する。
6. **最初の立ち絵表示** — 「画像を追加表示」からダウンロードした立ち絵PNGを選択する。透過できれいに表示された推しの立ち絵にテンションが上がる。「うわ、本当にデスクトップにいる！」とDiscordのファン仲間にスクリーンショットを送る。
7. **配置の調整** — 立ち絵を画面右端に大きめに配置し、スクロールホイールで高さを合わせる。配信視聴中のブラウザと並べてみて、「推しが隣で見てる感じ」の配置に落ち着く。
8. **2人目の推しを追加** — 同じ事務所の別のVTuberも推しているため、その立ち絵も追加する。2体の立ち絵が並んで表示され、「今日は2人と一緒に勉強する」という状況にひとりで喜ぶ。
9. **不透明度調整で集中モード** — 課題に集中したいときは不透明度を40%に下げて「うっすら存在してる」設定にする。完全に消すのは寂しいが、気が散りすぎないちょうどよい存在感を見つける。
10. **ファン仲間へのシェア** — Discordサーバーに「Sobani入れてみた！推しと一緒に勉強できる」とスクリーンショットを投稿する。同じファンから「かわいい！」「私も入れる！」と反応が集まり、サーバー内でSobaniの話題が広がる。
11. **配信スケジュールとの連動** — 推しの配信開始時間に合わせて立ち絵をフル表示に切り替え、配信終了後に不透明度を下げるのが日課になる。Option+Hで一括非表示できることを覚えてからは、学校のオンライン授業中に素早く隠せるようになり、Sobaniを「推し活と日常生活のスイッチ」として使いこなすようになる。
