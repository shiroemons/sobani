# Sobani（そばに）

> どんな画像も、常に目の前に。— macOS 画像最前面表示アプリ

**[公式サイト](https://xn--xckxf.jp/sobani/)** | [GitHub](https://github.com/shiroemons/sobani)

お気に入りの画像・写真・参考資料を、透明な背景でデスクトップの最前面に常時表示する macOS アプリケーションです。推しキャラのアクスタ風表示からデザイン作業の参考画像まで、用途を選ばず「好きな画像を最前面に飾る」ことに特化したシンプルな設計です。

## こんな使い方ができます

- **推しキャラのアクスタ風表示** — 透過PNGや背景除去で、推しをデスクトップに常駐。作業中もモチベーションアップ
- **デザイン・イラスト制作の参考画像** — 参考資料を最前面に固定して、アプリを切り替えずに確認
- **ペット・家族の写真** — お気に入りの写真をデジタルフォトフレームのように常時表示
- **配信・動画制作のオーバーレイ** — VTuber配信や動画制作で、画像素材を画面上に重ねて表示
- **学習・作業の資料表示** — 教材やチートシートを最前面に置いて、ながら学習・作業に

## 機能

- **最前面フローティングウィンドウ** — 透明な背景で画像を常に最前面に表示。全仮想デスクトップ対応
- **複数ウィンドウ** — 好きなだけ並べて表示。重ね順の管理、Option キー一括操作
- **直感的な操作** — ドラッグ移動、スクロールリサイズ、右クリックメニュー、ダブルクリックでフローティングツールバー
- **画像の管理** — PNG/JPEG/GIF/TIFF/HEIC 対応。登録・切り替え・デフォルト画像のカスタマイズ
- **表示の調整** — 回転（0〜360°）、不透明度（10%〜100%）、左右反転をウィンドウごとに設定
- **画像の切り取り** — iPhone 写真アプリ風クロップエディタ。アスペクト比プリセット、傾き・パースペクティブ補正、Undo/Redo。非破壊編集
- **ゴーストモード** — ウィンドウをクリック透過にして半透明表示。Option+G で一括切り替え。不透明度のカスタマイズ可能
- **簡易背景除去** — 写真から被写体をワンクリック切り抜き（macOS 標準 Vision フレームワーク使用）
- **管理パネル** — SwiftUI 製の統合管理画面。ミニマップでウィンドウ配置を俯瞰、不透明度・ゴーストモードの一括制御、登録画像の管理、ホットキー設定まで一画面で操作
- **レイアウトプリセット** — ウィンドウ配置を保存・ワンクリック復元。Undo 付き削除
- **ウィンドウ状態の保持** — 位置・サイズ・画像・回転・不透明度・ゴーストモードを終了時に自動保存、起動時に復元
- **画面復元** — モニター切断・スリープ復帰時にウィンドウ位置を自動復元（3フェーズ復元）
- **画面位置の診断ログ** — ウィンドウ位置の復元問題をデバッグするための診断ログ。JSONL/JSONエクスポート対応
- **自動アップデート** — Sparkle フレームワークによるセキュアな自動更新

## 他アプリとの違い

| | Sobani | 一般的な画像オーバーレイアプリ |
|---|---|---|
| 価格 | **完全無料・OSS** | 無料〜有料（$4.99〜） |
| 背景除去 | **ワンクリック（Vision AI）** | なし or 外部ツール必要 |
| 画像クロップ | **非破壊・アスペクト比プリセット付き** | なし or 基本的 |
| 複数ウィンドウ管理 | **レイアウトプリセット保存・復元** | 個別管理のみ |
| 画面復元 | **3フェーズ自動復元** | なし |
| 管理パネル | **ミニマップ・一括制御・設定を統合** | なし |
| ゴーストモード | **クリック透過＋不透明度調整** | 一部対応 |

## インストール

### Homebrew（推奨）

```sh
brew install --cask shiroemons/tap/sobani
```

### 手動インストール

[Releases](https://github.com/shiroemons/sobani/releases) ページから最新の DMG または ZIP をダウンロードしてください。

- **DMG**: ディスクイメージを開き、`Sobani.app` を `/Applications` にドラッグ＆ドロップ
- **ZIP**: 解凍後、`Sobani.app` を `/Applications` に移動

> **初回起動時**: 「開発元が未確認」と表示される場合は、`Sobani.app` を右クリック →「開く」を選択してください。Homebrew 経由なら不要です。

## クイックスタート

1. `Sobani.app` を起動 → メニューバーにアイコン（👤）が表示されます
2. デフォルト画像が画面中央に表示されます
3. **ドラッグ**で移動、**スクロール**でリサイズ、**右クリック**で各種操作
4. 画像ファイルをウィンドウに**ドラッグ＆ドロップ**で追加（Option+ドロップで差し替え）
5. **Option+H** で全ウィンドウの表示/非表示切り替え、**Option+Shift+H** で現在の画面のみ切り替え
6. **Option+G** でゴーストモード（クリック透過）を一括切り替え、
   **Option+Shift+G** で現在の画面のみ切り替え
7. **Option+M** で管理パネルを表示

> 詳しい操作方法は [操作ガイド](docs/guide/usage.md) をご覧ください。

## 対応画像形式

PNG（推奨）・JPEG / JPG・GIF・TIFF・HEIC

> スマホ写真（JPEG/HEIC）もそのまま使えます。背景を消したい場合は右クリック →「背景を除去」でワンクリック切り抜き。透過 PNG なら背景なしの最前面表示に。

## 開発

- **必要環境**: macOS 14.0+、Xcode 15.0+
- **ビルド**: `./build.sh`（SwiftLint 統合済み）
- **コードスタイル**: [SwiftLint](https://github.com/realm/SwiftLint)（`brew install swiftlint`）
